Workflow

1. Place IC(s) on the breadboard (they don't need power yet). 2. Wire VCC (pin 14) and GND (pin 7) — each IC pin is its own silver dot on the chip; hover any pin to see if it's VCC/GND/INPUT/OUTPUT. 3. Wire the logic switches to the input pins. 4. Wire the gate's OUTPUT pin (e.g. pin 3 on a 7408) to an LED. 5. Turn POWER ON last and toggle switches to test.

Once powered, every connected pin that's logic-HIGH glows faint green — even mid-circuit — so you can trace the signal from switch → input pin → output pin → LED. Each chip also gets a border around it: red = not properly powered, green = VCC+GND are correctly wired.
